# Third-party award badges

Drop each award badge image here so the homepage can display it in the
trust-signals section (e.g. Autotrader Highly Rated).

**Naming**: filename must match the award slug used on the homepage.

- `autotrader-highly-rated-2022.png`
- `autotrader-highly-rated-2021.png`

**Format**: `.png` at 240×240 (or an SVG that scales) — transparent
background is fine, the tile provides the surround.

**Sourcing**: Autotrader award badges are supplied to the winning
retailer via the Autotrader retailer portal. Download the badge from
there and drop it in as-is.

**Missing files**: any award without an image file falls back to a
neutral placeholder tile with the year and category, so the section
still renders while you gather the files.
